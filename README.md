# Loyalty
Программа лояльности для курса ПКС — консольное приложение на Java 27 + PostgreSQL (JDBC).

## Запуск

```bash
createdb loyalty                 # один раз; таблицы и стартовые правила создаются при запуске
mvn compile exec:java            # или: mvn package && java -jar target/Loyalty-1.0-SNAPSHOT.jar
```

Подключение настраивается в `src/main/resources/db.properties` или переменными окружения
`LOYALTY_DB_URL`, `LOYALTY_DB_USER`, `LOYALTY_DB_PASSWORD` (по умолчанию —
`jdbc:postgresql://localhost:5432/loyalty` под текущим пользователем ОС).

## Возможности

- **Клиенты** — регистрация (сразу открывается бонусный счёт с картой), поиск, карточка клиента, доп. счета, блокировка.
- **Бонусные счета** — баланс, история транзакций, заявки на начисление/списание, блокировка.
- **Покупки** — регистрация операции, списание бонусов в счёт оплаты, начисление на оплаченную деньгами часть, пересчёт уровня.
- **Списание бонусов** — заявка по операции → подтверждение / отмена; просроченная заявка получает статус `EXPIRED`.
- **Правила** — просмотр, добавление, включение/выключение правил начисления и списания.

Бизнес-правила:
- при начислении применяется самое выгодное из активных правил, подходящих по периоду действия и уровню счёта
  (`accrual_rule.category` = `BASE` / `SILVER` / `GOLD`, пусто — для всех);
- списание ограничено `max_percent` суммы операции, `min_amount`/`max_amount` и балансом; действует самое новое активное правило;
- уровень: `SILVER` от 10 000, `GOLD` от 50 000 суммарных покупок.

## Структура

```
src/main/java/org/example
├── Main.java, AppContext.java   точка входа и сборка зависимостей
├── config/                      параметры подключения
├── db/                          соединения, транзакции, JDBC-хелпер
├── model/                       сущности (таблицы БД) и перечисления статусов
├── repository/                  SQL-доступ, по классу на таблицу
├── service/                     бизнес-логика
│   ├── accrual/                 алгоритмы начисления по rule_type
│   └── tier/                    политика уровней
└── console/                     ввод/вывод, меню, разделы меню
src/main/resources/db            schema.sql, seed.sql
```

## Как расширять

| Что нужно | Что сделать |
|---|---|
| Новый тип правила начисления | реализовать `AccrualCalculator`, зарегистрировать в `AccrualCalculatorRegistry.defaults()` |
| Другая логика уровней | реализовать `TierPolicy`, передать в `AppContext` |
| Новый раздел меню | реализовать `MenuSection`, добавить в список разделов `AppContext` |
| Новый тип операции (возврат и т.п.) | добавить значение в `OperationType` и сервис-сценарий по образцу `PurchaseService` |
| Отложенное начисление | `AccrualService.process` уже отделён от создания заявки (`PENDING` → `APPROVED`/`REJECTED`) |
| Изменение схемы | `schema.sql` (идемпотентный, выполняется при каждом запуске) |
